RR 3D Kitchen Planner — Version 1
=================================

This is the first working prototype.

Included:
- 3D room with Length / Width / Height
- Add Unit library
- Base, drawer, wall, glass, tall, pantry, sink, hob, chimney, refrigerator
- Plain Panel and Ceiling Light
- Select an object in 3D
- Width / Height / Depth / Rotation / X / Z editing
- Handle style and horizontal/vertical orientation
- Door and cabinet colours
- Free placement (no automatic collision)
- Duplicate / Delete
- Front / Top / 3D views
- Mobile responsive sidebar

Not included by design:
- Quotation system
- Automatic collision
- Backend/login
- PDF library (will be a later module)
- Real GLB product models (will replace prototype boxes later)

How to run:
1. Put index.html on GitHub Pages, or open it from a local web server.
2. Internet is needed because this first prototype loads Three.js from a CDN.
3. Later we can move Three.js and all models into the project itself.

Next development module:
Replace the prototype cabinet shapes with proper GLB/GLTF kitchen models and build the full Add Unit panels matching the reference screenshots.
