RR 3D Kitchen Planner V43 — Material & Texture Studio

Adds a professional material/texture layer over V42:
- Acrylic, Laminate, PU, Glass, Aluminium, Stainless Steel, HDHMR, BWP presets
- Procedural wood/laminate texture generation
- Roughness, metalness, clearcoat, opacity and texture scale controls
- Apply/restore material per selected object hierarchy
- V43 metadata stored on selected object

This is a prototype PBR-style material system. Replace procedural textures with licensed manufacturer textures for production.
