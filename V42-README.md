# RR 3D Kitchen Planner V42
Real Cabinet Editor added on top of V41 Core Stable.

Features:
- Width/Height/Depth in mm applied to selected 3D object
- Shutters, drawers, shelves metadata
- Finish, handle, opening and orientation metadata
- Add shelf/shutter/drawer helpers
- Existing V1-V41 functionality retained in active build
- Collision OFF, Fit Warning OFF, no quotation system

Note: This is a prototype editor. Manufacturing dimensions should be verified against the actual cabinet construction and hardware before production.
